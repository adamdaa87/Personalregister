# Personalregister

Personalregister is a simple .NET console application for registering one employee at a time by entering a name and wage, then printing the saved information in the terminal.

## What the application does

- Waits for user input to start a new employee registration
- Reads an employee name
- Reads an employee wage
- Displays the registered employee information
- Repeats until the user presses **Enter** on the start prompt

## Tech stack

- C#
- .NET 5 console app

## Run the project

From the repository root:

```bash
dotnet run --project Exercise1/Exercise1.csproj
```

Or build the solution:

```bash
dotnet build Personalregister.sln
```
